# docs/plans/

- [`roadmap.md`](roadmap.md) — multi-year view: what gets built and learned when.
- `YYYY-season-plan.md` — one file per beekeeping year (Feb–Jan), month by
  month, with checkboxes. The `season-planner` agent updates it from the
  calendar in `../apiary/seasonal-calendar.md` and the logs in `../../logs/`.

Plans point at research notes for the *why*; they don't repeat them.
