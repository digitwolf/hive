# 2027 season plan

First bees. Two Flow Hive 2+ colonies, `hive-a` and `hive-b`.
Dates are targets; the calendar in `../apiary/seasonal-calendar.md` explains
the why. Tick things off and add the real date.

## January
- [ ] Order 2 nucs (local supplier, pickup late April) — or packages as
      fallback.
- [ ] WSDA registration submitted.
- [ ] Node v0 on the bench publishing to Grafana.

## February
- [ ] Stand built and levelled; scale platforms built; hives dry-fitted on
      them.
- [ ] Mixing bucket, feeders, sugar stock on hand.

## March
- [ ] Nodes in enclosures, installed on the stand, running empty for 4+
      weeks to catch weatherproofing problems *before* bees.
- [ ] Water source set up and running.

## April
- [ ] Pick up nucs. Install on a warm calm afternoon. Feed 1:1 syrup.
- [ ] Tare the scales with the empty box configuration recorded in the log.
- [ ] First inspection at day 7: queen laying? Log it.

## May
- [ ] Inspections every 7–10 days; watch for swarm cells (unlikely from a
      nuc in year one but possible).
- [ ] Add second brood box when 7–8 frames are covered.
- [ ] First mite wash (alcohol, 300 bees).

## June
- [ ] Blackberry flow: stop feeding once it starts. Add Flow super to any
      colony with a fully drawn second box; otherwise skip.
- [ ] Second mite wash.

## July
- [ ] Harvest only capped Flow frames, if any.
- [ ] Mite wash → decide treatment.

## August
- [ ] Mite treatment (Formic Pro if highs < 29 °C; Apiguard otherwise).
- [ ] Entrances reduced; robbing screens if needed.
- [ ] Remove Flow supers.

## September
- [ ] Feed 2:1 to target ~25–30 kg stores per hive (read it off the scale).
- [ ] Post-treatment mite wash.

## October
- [ ] Mouse guards, insulation, moisture quilt, strap, tilt.
- [ ] Record winter baseline weight and node battery/power state.

## November–December
- [ ] Oxalic acid on a broodless day.
- [ ] Otherwise hands off; watch the dashboard.
